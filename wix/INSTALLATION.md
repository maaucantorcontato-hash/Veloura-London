# Wix Studio installation plan

1. Open the existing VELOURA project in Wix Studio, not the older HTML site.
2. Upload `assets/brand/wordmark-dark.svg` or the previously supplied **transparent PNG** version to Media if you want an image-based logo. The existing styled text VELOURA is also a valid wordmark. Do not place both logos in the same header.
3. Keep native Wix `Menu` and `Cart` functionality in mobile; style the background ivory and match the typography to the Figma layout. Do not make the header a flat screenshot.
4. Use `assets/brand/favicon-cream.svg` (or the PNG favicon from the separate kit) in site favicon settings if accepted.
5. Do **not** replace working Store Product Page, Checkout, forms or cart with static HTML images.
6. Product cards imported from Figma can link to product detail pages. Simple links do **not** implement dynamic Add to Cart, stock, variants, filters or checkout by themselves.
7. Do not upload `assets/creative-concepts/` imagery as actual product listings. Replace with verified authorised supplier photography when available.
8. Review both breakpoints and test navigation and an end-to-end checkout only after Wix billing and payment-provider setup are resolved.

## Note

GitHub does not automatically sync assets into a Wix Studio design. Upload/select media manually or use a separately configured, authorised Wix integration. Replacing repository files does not modify Wix layouts.
